# forever-radial-bars

## 0.0.1

### Initial release

- Turn one action bar (2-8) into a radial wheel opened by a hotkey.
- Toggle mode (press, then click a slot) and Hold mode (point toward a slot, release to use it).
- Open at screen center, the mouse cursor, or a fixed position placed by dragging the preview.
- Square, circle, or radial slice icons, with sliders for button count, icon size, spacing, margin, center size, slice gap, and opacity.
- The selected ability's name and description show in the center, which also cancels.
- Works in combat.
